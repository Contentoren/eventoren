# Fiktives UI/UX-Testevent

## Ziel
Ein zusätzliches, eindeutig als fiktiv gekennzeichnetes und veröffentlichtes Event in der öffentlichen Eventliste bereitstellen.

## Entscheidung
Das Event wird über die bestehende Convex-Katalogverwaltung angelegt und veröffentlicht, damit es auf der gezeigten Startseite erscheint. Es wird kein Produktcode und keine Demo-Route geändert.

## Vorgehen
1. Bestehende Katalog- und Veröffentlichungsbefehle ermitteln und ein fiktives Event mit vollständigen Anzeigeinformationen anlegen.
2. Das Event veröffentlichen und in der öffentlichen Eventliste prüfen.

## Aufgaben
1. Katalogzugriff und geeignete fiktive Eventdaten bestimmen und das Event anlegen.
2. Event veröffentlichen und das Auftauchen in der öffentlichen Liste verifizieren.
