A presale code is an access code that unlocks a ticket type which is otherwise hidden or locked in the ticket shop. It lets you sell tickets first, or exclusively, to a chosen group: club members, a fan club, newsletter subscribers, sponsors, or the families of a graduating class. Done well, a presale rewards loyal fans, brings in early sales and builds attention before the public on-sale. Done badly, the code lands in a public group chat on the first evening. This guide shows how to plan presale formats, design and distribute codes securely, and what to write, as of November 2026.

> **Key takeaways**
>
> - A presale or unlock code makes a protected ticket type visible and buyable. Without the code, buyers can't purchase it.
> - Typical presale groups: members, fan clubs, newsletter subscribers, sponsors and partners, graduation-ball guests, volunteers.
> - One random, one-time code per person beats one shared code for everyone. A good code looks like "K7M2Q9XA", not "MEMBER001".
> - Announce presale and public sale dates together, and keep the presale short, typically 1–7 days.
> - A per-type allocation and a per-order limit cap what any leaked code can do.

## What is a presale code?

A **presale code** is an access code that lets a selected group buy tickets before the general public. An **unlock code** (also called access code or access key) is the broader technical term: a code that unlocks a protected ticket type in the shop, whether for early access, a members' price or a guest-only allocation.

Platforms name it differently, but the pattern is always the same:

1. You create a ticket type that is not publicly buyable.
2. Codes are generated and linked to that ticket type, either by you or by the platform.
3. Whoever enters a valid code can see and buy that ticket type.

### Presale codes vs discount codes

| Code type              | What happens                                                      | Typical use                                                 |
| ---------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------- |
| Unlock or presale code | a hidden ticket type becomes available                            | members' presale, guest allocations, sponsors, school balls |
| Discount code          | the price of a public ticket type drops by a percentage or amount | promotions, influencers, returning buyers                   |
| Voucher code           | a prepaid value is redeemed at checkout                           | gift vouchers, corporate allocations                        |

An unlock code can still lead to a lower price: "Members – €12" next to "Standard – €15" is its own ticket type, not a discount on the standard one.

## Which presale formats work for which group?

| Group                          | Goal                                              | Code form                             | Timing                                        | Tip                                                          |
| ------------------------------ | ------------------------------------------------- | ------------------------------------- | --------------------------------------------- | ------------------------------------------------------------ |
| Club or association members    | priority access, members' price                   | one code per member or household      | 5–7 days before public sale                   | send with the members' newsletter or AGM invitation          |
| Fan club                       | reward loyalty                                    | one code per registered fan           | 1–3 days before                               | state the allocation size to avoid disappointment            |
| Newsletter subscribers         | grow and keep your list                           | one code per subscriber               | 1–2 days before                               | ask subscribers to confirm their address in time             |
| Sponsors and partners          | contractual ticket allocation                     | one code per sponsor, own ticket type | any time, often free or reduced               | fix the allocation in the sponsorship contract               |
| Graduation ball or school prom | only families and friends of graduates            | one code per graduate                 | after graduates have bought their own tickets | per-order limit = guests per graduate                        |
| Volunteers and crew            | free or crew-price tickets                        | one code per volunteer                | before public sale                            | own ticket type keeps them separate in reports               |
| School community               | school concert or play first for pupils' families | one code per family                   | 1–2 weeks before                              | teachers or the parents' association hand out codes          |
| Previous attendees             | keep your regular crowd                           | one code per buyer                    | 3–5 days before                               | check you have a lawful basis to email them (GDPR, ePrivacy) |

A presale is worth it when capacity is tight and one group matters most. For an event that never sells out, a presale can feel staged. Combining a presale with an early bird price is covered in [early bird tickets](/en/guides/early-bird-tickets).

## One shared code or one code per person?

This is the most important decision, because it determines how safe your allocation is.

| Option                           | Advantage                      | Drawback                                | Good for                                               |
| -------------------------------- | ------------------------------ | --------------------------------------- | ------------------------------------------------------ |
| One shared code ("FANCLUB2027")  | easy to communicate            | gets passed around, abuse hard to trace | low-stakes newsletter presales with a small allocation |
| One code per group               | reporting per group            | can be shared inside the group          | sponsors, departments, school classes                  |
| One code per person ("K7M2Q9XA") | a leak affects one person only | more work to distribute                 | members, school balls, fan clubs with a list           |

**Rule of thumb:** the scarcer the allocation and the bigger the price advantage, the more you need individual codes. A single code for a cheap members' price will almost certainly be shared.

### What does a good code look like?

A good unlock code is **random and unguessable**.

- **Random, not sequential.** "MEMBER001", "MEMBER002" can be tried through in minutes. An eight-character random code avoids that.
- **One per person.** You know who received which code, and a leaked code affects only one recipient.
- **One-time use.** A code that is consumed after one order turns the per-order limit into a hard cap per person, for example the number of guests per graduate.
- **Groups via ticket types.** The most reliable way to see where sales came from is the ticket type ("Members", "Sponsors", "Crew") plus your list of code recipients.

Some systems allow fixed prefixes such as "BALL-" to mark a group inside the code. It's convenient but not necessary; separate ticket types do the same job.

## How do you distribute codes securely?

A code is only as exclusive as the channel it travels through.

- **Address people individually:** a personal email, a letter, a members' portal or handing it over in person. Never a social post or an open Facebook group.
- **Avoid group chats:** even "internal" WhatsApp or Telegram groups contain former members, friends and parents. Send codes one by one.
- **Cap the allocation:** give each code-protected ticket type its own allocation, so a leak can only do limited damage.
- **Set the per-order limit to the group:** for a school ball, the number of guests each graduate may bring.
- **Use participant names:** if each ticket carries a name, you can see who bought and follow up on anything odd.
- **Keep a code list:** code, recipient, date sent. Delete it when you no longer need it (GDPR data minimisation).
- **Review after the presale:** compare sales per ticket type with the number of codes sent out.

### What if a code goes public?

1. Check how many tickets have been sold in that ticket type.
2. Lower the allocation to the number sold, or close the ticket type.
3. Create a new ticket type for the legitimate group, with new individual codes.
4. Communicate briefly and calmly (template below).
5. Don't cancel tickets bought with the leaked code across the board. Decide case by case, following your terms and conditions.

Bots and bulk buyers are a separate risk. Under EU law it is already a blacklisted practice to resell tickets acquired with automated means that bypass purchase limits (UCPD Annex I, No. 23a). Per-order limits are therefore worth setting even outside presales.

## What does a good presale timeline look like?

Announce both dates, presale and public sale, together from the start. Then everyone knows the rules and the general public doesn't feel shut out.

### Worked example: a club's 100th anniversary party for 600 guests

| When                    | Step                                                                           |
| ----------------------- | ------------------------------------------------------------------------------ |
| 6 weeks before          | create ticket types, request or generate codes, match codes to the member list |
| 5 weeks before          | announce to everyone: "Members' presale from Monday, public sale from Friday"  |
| Monday 6 pm             | members receive their personal code by email; members' ticket type opens       |
| Thursday                | reminder to members who have not bought yet                                    |
| Friday 6 pm             | public sale opens; members' type stays open or closes                          |
| 1 week before the event | move unsold members' allocation to the public ticket type                      |

Allocation plan (worked example):

| Ticket type | Allocation                | Per-order limit | Price | Code              |
| ----------- | ------------------------- | --------------- | ----- | ----------------- |
| Members     | 240                       | 2               | €12   | one per member    |
| Sponsors    | 30                        | as agreed       | free  | one per sponsor   |
| Crew        | 30                        | 1               | free  | one per volunteer |
| Public      | 600 − 240 − 30 − 30 = 300 | 10              | €15   | none              |

If members buy only 180 tickets, cut that type to 180 after the presale and raise the public type by 60 to 360. The sum of all allocations must never exceed 600. At a sell-out with the fee paid by buyers: 180 × €12 + 360 × €15 = €2,160 + €5,400 = €7,560 in ticket revenue. Free tickets carry no Eventoren fee.

## What should you write? Presale templates

Good presale messages answer three questions: when, for whom, and how many.

### Template 1: announcement to everyone

> On Saturday 12 June 2027 we celebrate 100 years of our club. Tickets go on sale in two stages:
>
> - **Members:** from Monday 3 May, 6 pm, with a personal code, €12 per ticket, up to 2 tickets per order
> - **Everyone:** from Friday 7 May, 6 pm, €15 per ticket
>
> Members will receive their code by email on Monday.

### Template 2: personal code to a member

> Subject: Your personal code for the anniversary party
>
> Hi Sofia,
>
> from 6 pm today you can buy tickets at the members' price. Your personal code is: **K7M2Q9XA**
>
> How it works: open the ticket shop, enter the code, choose the members' ticket. The code is valid for one order of up to 2 tickets.
>
> Please don't share it. It's for you only, and the members' allocation is limited. The public sale opens on Friday.

### Template 3: school ball guests

> Dear Murphy family,
>
> you're invited to the Class of 2027 graduation ball on 3 July. With the code **T4WQ8R2N** you can buy up to 3 guest tickets in one order. The code works for a single order only, so please book all your guests at once. Guest tickets are not available without a code.

### Template 4: a code was leaked

> A members' code was posted in a public group. We've closed the affected ticket type. All members who haven't bought yet will receive a new personal code today. Tickets already bought remain valid.

If you email previous buyers, check your legal basis first: marketing emails need consent, or must meet the existing-customer exception under the ePrivacy rules. More in [GDPR for event organisers](/en/guides/gdpr-for-event-organisers).

## Checklist: run a presale in 12 steps

- [ ] Define the goal: priority access, reward, protect an allocation or early sales
- [ ] Choose the groups and estimate their size
- [ ] Create one ticket type per group with name, price and allocation
- [ ] Set the per-order limit to match the group
- [ ] Choose the code form: shared, per group or per person
- [ ] Generate or request random, unguessable codes, one per recipient
- [ ] Keep a code list with recipients only as long as needed
- [ ] Fix and announce presale and public sale dates together
- [ ] Distribute codes individually, never publicly
- [ ] Watch sales per ticket type on presale day
- [ ] Move unsold presale allocation to the public type afterwards
- [ ] Review after the event: codes used, guests checked in per type

On the day, check-in statistics per ticket type show how many members, sponsors and crew actually came. See [QR code ticket check-in](/en/guides/qr-code-ticket-check-in).

## Frequently asked questions

### What is a presale code?

A presale code is an access code that lets a selected group buy tickets before the general public, such as fan club members, newsletter subscribers or club members. It unlocks a ticket type in the shop that is otherwise hidden or locked.

### What is the difference between an unlock code and a discount code?

An unlock code makes a protected ticket type visible and buyable. A discount code lowers the price of a public ticket type. You can offer a members' price either way: as its own cheaper ticket type behind an unlock code, or as a discount on the standard ticket.

### How do I stop presale codes from being shared?

You can't stop it completely, but you can limit the damage. Use individual one-time codes instead of one shared code, give the protected ticket type its own allocation and a sensible per-order limit, and send codes personally rather than posting them. If a code still leaks, close the ticket type and issue new codes.

### How long before the public sale should a presale start?

For clubs and local events, 3–7 days is common; fan club and newsletter presales often run 1–3 days. Announce both dates at the same time so the general public knows when its turn comes.

### Can I use codes to enforce a guest limit at a school ball?

Yes, if each code works for one order only. Each graduate gets a personal code for the guest ticket type, and the per-order limit equals the allowed number of guests. Once the order is paid the code is used up, so extra guests need a second code from the committee.
