Ein Presale- oder Freischaltcode ist ein Zugangscode, der im Ticketshop eine sonst unsichtbare oder gesperrte Ticketart freigibt. Damit verkaufst du Tickets zuerst oder ausschließlich an eine bestimmte Gruppe: Vereinsmitglieder, Fanclub, Newsletter-Abonnenten, Sponsoren oder die Gäste eines Abijahrgangs. Gut gemacht belohnt ein Presale treue Fans, bringt früh Geld in die Kasse und erzeugt Aufmerksamkeit vor dem öffentlichen Verkaufsstart. Schlecht gemacht landet der Code am ersten Abend in einer öffentlichen WhatsApp-Gruppe. Hier erfährst du, wie du Codes planst, verteilst, absicherst und kommunizierst.

> **Das Wichtigste in Kürze**
>
> - Ein Freischaltcode macht eine geschützte Ticketart sichtbar und kaufbar. Ohne Code sieht der Käufer sie nicht.
> - Typische Presale-Gruppen: Mitglieder, Fanclub, Newsletter, Sponsoren und Partner, Abiball-Gäste, Helfer.
> - Ein Code pro Person ist sicherer als ein Sammelcode für alle. Gute Codes sind zufällig und nicht zu erraten, etwa „K7M2Q9XA“.
> - Plane den Presale 3–7 Tage vor dem allgemeinen Verkauf und kündige beide Termine gleichzeitig an.
> - Kontingent pro Ticketart und Höchstzahl pro Bestellung begrenzen, wie viel über einen Code verkauft wird.
> - Rabatt- oder Gutscheincodes sind etwas anderes: Sie senken den Preis, Freischaltcodes schalten eine Ticketart frei.

## Was ist ein Presale-Code und was ein Freischaltcode?

Ein **Presale-Code** ist ein Zugangscode, mit dem eine ausgewählte Gruppe Tickets vor dem öffentlichen Vorverkauf kaufen darf. Ein **Freischaltcode** ist der technische Oberbegriff: ein Code, der im Ticketshop eine geschützte Ticketart freischaltet, egal ob für einen frühen Verkauf, einen Mitgliederpreis oder ein reines Gästekontingent.

Anbieter nennen das Prinzip unterschiedlich (Stand: November 2026): Zugangsschlüssel, Zugangscode, Unlock-Code, Access Code oder Presale-Code. Gemeint ist immer dasselbe Muster:

1. Du legst eine Ticketart an, die nicht öffentlich sichtbar ist.
2. Codes werden erzeugt und mit dieser Ticketart verbunden, je nach System von dir selbst oder vom Anbieter.
3. Wer einen Code eingibt, sieht die Ticketart und kann kaufen.

### Abgrenzung zu Rabatt- und Gutscheincodes

| Codeart                       | Was passiert                                                        | Typischer Einsatz                                          |
| ----------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------- |
| Freischaltcode / Presale-Code | Eine versteckte Ticketart wird sichtbar                             | Mitglieder-Vorverkauf, Gästekontingent, Sponsoren, Abiball |
| Rabattcode                    | Der Preis einer öffentlichen Ticketart sinkt um Prozent oder Betrag | Aktionen, Influencer, Wiederkäufer                         |
| Gutscheincode                 | Ein vorab bezahlter Wert wird beim Kauf angerechnet                 | Geschenkgutscheine, Firmenkontingente                      |

Ein Freischaltcode kann trotzdem zu einem günstigeren Preis führen, nämlich dann, wenn die freigeschaltete Ticketart günstiger ist. „Mitglieder – 12 €“ statt „Regulär – 15 €“ ist eine eigene Ticketart, kein Rabatt auf die reguläre.

## Für welche Gruppen lohnt sich ein Presale?

| Gruppe                | Ziel                                                      | Codeform                               | Zeitpunkt                              | Tipp                                                                       |
| --------------------- | --------------------------------------------------------- | -------------------------------------- | -------------------------------------- | -------------------------------------------------------------------------- |
| Vereinsmitglieder     | Mitglieder bevorzugen, Mitgliederpreis                    | ein Code pro Mitglied oder Familie     | 7 Tage vor öffentlichem Start          | Code mit der Einladung zur Mitgliederversammlung oder im Mitgliederbrief   |
| Fanclub               | Treue belohnen, Tickets vor allen anderen sichern         | ein Code pro Fanclub-Mitglied          | 2–3 Tage vorher                        | Kontingent klar nennen, damit keine Enttäuschung entsteht                  |
| Newsletter            | Abonnenten gewinnen und halten                            | ein Sammelcode im Newsletter           | 1–2 Tage vorher                        | Sammelcodes nur mit begrenztem Kontingent                                  |
| Sponsoren und Partner | Gegenleistung aus dem Sponsoringvertrag                   | ein Code pro Sponsor, eigene Ticketart | jederzeit, oft kostenlos oder ermäßigt | Kontingent im Vertrag festlegen                                            |
| Abiball-Gäste         | nur Familie und Freunde der Abiturienten                  | ein Code pro Abiturient                | nach dem Abiturienten-Verkauf          | Höchstzahl pro Bestellung = Gäste pro Abiturient                           |
| Helfer und Crew       | Freikarten oder Crewpreis                                 | ein Code pro Helfer                    | vor dem öffentlichen Start             | eigene Stufe, damit Helfer in der Statistik getrennt sind                  |
| Schüler einer Schule  | Schulkonzert oder Theater vorab für die Schulgemeinschaft | ein Code pro Klasse                    | 1–2 Wochen vorher                      | Klassenlehrer verteilen den Code                                           |
| Vorjahreskäufer       | Stammpublikum binden                                      | ein Code pro Käufer                    | 3–5 Tage vorher                        | nur mit zulässiger Werbe-Einwilligung oder Bestandskundenregel anschreiben |

Ein Presale lohnt sich vor allem, wenn deine Kapazität knapp ist und eine Gruppe besonders wichtig ist. Bei einem Event, das ohnehin nie ausverkauft ist, wirkt ein Presale schnell aufgesetzt.

## Ein Code für alle oder ein Code pro Person?

Das ist die wichtigste Entscheidung beim Presale. Sie bestimmt, wie sicher dein Kontingent ist.

| Variante                                                                | Vorteil                                | Nachteil                                            | Geeignet für                              |
| ----------------------------------------------------------------------- | -------------------------------------- | --------------------------------------------------- | ----------------------------------------- |
| Ein Sammelcode für alle („FANCLUB2027“)                                 | einfach zu kommunizieren               | wird weitergegeben, Missbrauch kaum nachvollziehbar | Newsletter-Presale mit kleinem Kontingent |
| Ein Code pro Gruppe (z. B. je ein Code für Jugendabteilung und Sponsor) | Auswertung pro Gruppe, überschaubar    | innerhalb der Gruppe weitergebbar                   | Sponsoren, Abteilungen, Klassen           |
| Ein Code pro Person („K7M2Q9XA“)                                        | Missbrauch auf eine Person eingrenzbar | Verteilung aufwendiger                              | Mitglieder, Abiball, Fanclub mit Liste    |

**Faustregel:** Je knapper das Kontingent und je größer der Preisvorteil, desto eher brauchst du Einzelcodes. Ein Massen-Code für einen günstigen Mitgliederpreis wird fast sicher geteilt.

### Wie sieht ein guter Code aus?

Ein guter Freischaltcode ist **zufällig und nicht zu erraten**. Fortlaufende Codes wie „MITGLIED001“, „MITGLIED002“, „MITGLIED003“ probiert jemand in wenigen Minuten durch. Ein zufälliger Code aus acht Zeichen wie „K7M2Q9XA“ lässt sich praktisch nicht erraten.

- **Ein Code pro Person:** So weißt du, wer welchen Code bekommen hat, und ein geleakter Code betrifft nur eine Person.
- **Einmal nutzbar:** Ideal ist ein Code, der nach einer Bestellung verbraucht ist. Zusammen mit der Höchstzahl pro Bestellung wird er so zur festen Obergrenze pro Person, zum Beispiel für die Gäste eines Abiturienten.
- **Gruppen über Ticketarten trennen:** Woher ein Kauf stammt, erkennst du am zuverlässigsten an der Ticketart, also „Mitglieder“, „Sponsoren“ oder „Helfer“, und an deiner Code-Liste mit Empfängern.

Manche Systeme erlauben einen festen Präfix wie „ABI-“, der die Gruppe im Code selbst kennzeichnet. Das ist praktisch, aber nicht nötig. Bei Eventoren sind Freischaltcodes immer zufällige Codes aus acht Zeichen ohne eigenen Präfix.

## Wie verteilst du Codes sicher?

Codes sind nur so exklusiv wie der Weg, auf dem sie verteilt werden. Diese Regeln haben sich bewährt:

- **Persönlich adressieren:** E-Mail an die einzelne Person, Brief, Mitgliederbereich oder persönliche Übergabe. Kein Posting in Social Media, keine offene Facebook-Gruppe.
- **Keine Codes in öffentlichen Kanälen wiederverwenden:** Ein Code, der einmal in einer großen WhatsApp-Gruppe oder Story stand, gilt als öffentlich. Für den nächsten Presale brauchst du neue Codes.
- **Gruppenchats meiden:** Selbst in „internen“ Gruppen sind oft Ehemalige, Freunde oder Eltern. Lieber die Codes einzeln schicken.
- **Kontingent begrenzen:** Lege für jede Code-Ticketart ein eigenes Kontingent fest. Selbst wenn ein Code durchsickert, ist der Schaden begrenzt.
- **Höchstzahl pro Bestellung:** Setze sie passend zur Gruppe. Beim Abiball etwa auf die Zahl der Gäste pro Abiturient.
- **Teilnehmernamen nutzen:** Wenn jedes Ticket einen Namen trägt, siehst du, wer gekauft hat, und kannst Auffälligkeiten nachgehen.
- **Liste führen:** Eine Tabelle mit Code, Empfänger und Versanddatum hilft, wenn Fragen kommen oder ein Code in falsche Hände gerät.
- **Nach dem Presale prüfen:** Vergleiche Käufe pro Ticketart mit der Zahl der verteilten Codes. Ungewöhnlich viele Bestellungen in einer Stufe sind ein Warnzeichen.

### Was tun, wenn ein Code öffentlich wird?

1. Ruhe bewahren und prüfen, wie viele Tickets in der Stufe verkauft wurden.
2. Das Kontingent der Stufe auf die verkaufte Zahl senken oder die Stufe schließen.
3. Für die berechtigte Gruppe eine neue Stufe mit neuen Einzelcodes anlegen.
4. Kurz und sachlich kommunizieren: „Der Code wurde öffentlich geteilt. Alle Mitglieder bekommen heute einen neuen persönlichen Code.“
5. Bereits gekaufte Tickets aus dem geleakten Code nicht pauschal stornieren, sondern im Einzelfall entscheiden. Was deine AGB dazu sagen, ist maßgeblich.

## Wie sieht ein guter Presale-Zeitplan aus?

Ein Presale funktioniert am besten, wenn beide Termine, Presale und öffentlicher Verkauf, von Anfang an feststehen und gemeinsam angekündigt werden. So weiß jeder, woran er ist, und das öffentliche Publikum fühlt sich nicht übergangen.

### Beispiel: Vereins-Jubiläumsfest mit 600 Plätzen

| Zeitpunkt                      | Schritt                                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| 6 Wochen vorher                | Ticketarten anlegen, Codes erzeugen oder anfordern, Code-Liste mit Mitgliedern verknüpfen |
| 5 Wochen vorher                | Ankündigung an alle: „Mitglieder-Vorverkauf ab Montag, öffentlicher Verkauf ab Freitag“   |
| 5 Wochen vorher, Montag 18 Uhr | Mitglieder bekommen ihren persönlichen Code per E-Mail, Mitglieder-Stufe öffnet           |
| Donnerstag                     | Erinnerung an Mitglieder, die noch nicht gekauft haben                                    |
| Freitag 18 Uhr                 | Öffentlicher Verkauf startet, Mitglieder-Stufe läuft weiter oder schließt                 |
| 1 Woche vorher                 | Restkontingent der Mitglieder-Stufe in die öffentliche Stufe umschichten                  |

### Kontingente planen: Beispielrechnung

- Kapazität: 600
- Mitglieder: 240, erwartet wird, dass etwa die Hälfte kommt, jeweils mit einer Begleitung
- Mitglieder-Stufe: 240 Tickets, Höchstzahl pro Bestellung 2, Preis 12 €
- Sponsoren-Stufe: 30 Tickets, kostenlos, eigener Code pro Sponsor
- Helfer-Stufe: 30 Tickets, kostenlos
- Öffentliche Stufe: 600 − 240 − 30 − 30 = **300 Tickets**, 15 €

Werden in der Mitglieder-Stufe nur 180 Tickets verkauft, senkst du deren Kontingent nach dem Presale auf 180 und erhöhst die öffentliche Stufe um 60 auf 360. Die Summe aller Kontingente darf dabei nie über 600 liegen.

**Einnahmen in dieser Beispielrechnung** bei vollem Verkauf und Gebühr bei den Käufern: 180 × 12 € + 360 × 15 € = 2.160 € + 5.400 € = 7.560 €. Freikarten erzeugen bei Eventoren keine Gebühren (Stand: November 2026).

## Welche Texte brauchst du für den Presale?

Gute Presale-Kommunikation beantwortet drei Fragen: Wann? Für wen? Wie viel? Diese Vorlagen kannst du anpassen.

### Vorlage 1: Ankündigung an alle

> Am Samstag, 12. Juni 2027, feiern wir 100 Jahre TSV. Der Vorverkauf startet in zwei Stufen:
>
> - **Mitglieder:** ab Montag, 3. Mai, 18 Uhr, mit persönlichem Code, 12 € pro Ticket, bis zu 2 Tickets pro Bestellung
> - **Alle:** ab Freitag, 7. Mai, 18 Uhr, 15 € pro Ticket
>
> Mitglieder bekommen ihren Code am Montag per E-Mail.

### Vorlage 2: Code an Mitglieder

> Betreff: Dein persönlicher Code für das Jubiläumsfest
>
> Hallo Andrea,
>
> ab heute 18 Uhr kannst du Tickets zum Mitgliederpreis kaufen. Dein persönlicher Code lautet: **K7M2Q9XA**
>
> So geht's: Ticketshop öffnen, Code eingeben, Mitglieder-Ticket wählen. Der Code gilt für eine Bestellung mit bis zu 2 Tickets.
>
> Bitte gib den Code nicht weiter. Er gilt nur für dich, und das Mitgliederkontingent ist begrenzt.
>
> Der öffentliche Verkauf startet am Freitag.

### Vorlage 3: Abiball-Gäste

> Liebe Familie Yilmaz,
>
> Ihr seid zum Abiball am 3. Juli 2027 eingeladen. Mit dem Code **T4WQ8R2N** könnt ihr Gästetickets kaufen, bis zu 3 in einer Bestellung. Der Code gilt nur für eine Bestellung, bestellt also alle eingeplanten Gäste auf einmal. Der Code ist nur für euch. Gästetickets sind ohne Code nicht erhältlich.

### Vorlage 4: Code wurde geteilt

> Leider wurde ein Mitglieder-Code in einer öffentlichen Gruppe gepostet. Wir haben die betroffene Ticketstufe geschlossen. Alle Mitglieder, die noch nicht gekauft haben, bekommen heute einen neuen persönlichen Code. Bereits gekaufte Tickets bleiben gültig.

Wenn du an Vorjahreskäufer schreibst, achte auf das Werberecht: Werbe-E-Mails brauchen eine Einwilligung oder müssen die Bedingungen für Bestandskunden nach § 7 Abs. 3 UWG erfüllen. Mitglieder kannst du über die Vereinskommunikation erreichen, die deine Satzung und Datenschutzinformation vorsehen.

## Checkliste: Presale in 12 Schritten

- [ ] Ziel festlegen: bevorzugen, belohnen, Kontingent schützen oder früh Geld einnehmen?
- [ ] Gruppen bestimmen und Größe schätzen
- [ ] Pro Gruppe eine eigene Ticketart mit Name, Preis und Kontingent anlegen
- [ ] Höchstzahl pro Bestellung passend zur Gruppe setzen
- [ ] Codeform wählen: Sammelcode, Gruppencode oder Einzelcode
- [ ] Zufällige, nicht erratbare Codes erzeugen oder beim Anbieter anfordern, einen pro Empfänger
- [ ] Code-Liste mit Empfängern führen (nur so lange wie nötig, DSGVO)
- [ ] Termine für Presale und öffentlichen Verkauf festlegen und gemeinsam ankündigen
- [ ] Codes persönlich verteilen, nicht öffentlich posten
- [ ] Am Presale-Tag Verkäufe pro Stufe beobachten
- [ ] Nach dem Presale Restkontingente in die öffentliche Stufe umschichten
- [ ] Nach dem Event auswerten: Wie viele Codes wurden genutzt, wie viele Gäste kamen pro Stufe?

## So setzt du das mit Eventoren um

Eventoren arbeitet mit **Freischaltcodes**, die Ticketstufen freischalten. Du markierst eine Ticketstufe als „nur mit Freischaltcode“. Die Codes erstellt das Eventoren-Team auf Anfrage für die freigeschaltete Ticketstufe, bis zu 500 pro Durchgang, und du bekommst sie als CSV/PDF-Liste zum Verteilen. Jeder Code besteht aus acht zufälligen Zeichen wie „K7M2Q9XA“, ohne eigenen Präfix. Ohne Code ist die Stufe im Shop nicht kaufbar.

Jeder Code gilt für **genau eine Bestellung** in seiner Ticketstufe, bis zur Höchstzahl pro Bestellung dieser Stufe. Während des Checkouts ist der Code 15 Minuten reserviert, nach der Zahlung ist er verbraucht. Damit wird die Höchstzahl pro Bestellung zur festen Obergrenze pro Person, etwa für die Gäste eines Abiturienten.

So bildest du das Beispiel oben ab:

- **Mitglieder-Stufe** mit Kontingent 240, Höchstzahl pro Bestellung 2, nur mit Freischaltcode, ein Code pro Mitglied
- **Sponsoren- und Helfer-Stufe** als kostenlose Stufen mit eigenem Kontingent und eigener Code-Liste. Gratis-Tickets kosten keine Gebühr.
- **Öffentliche Stufe** ohne Code mit dem Restkontingent

Jede Ticketstufe hat ein eigenes Kontingent und eine Höchstzahl pro Bestellung (Standard: 10). Codes mit eigener Stückzahl oder Ablaufdatum gibt es nicht, auch keine Sammelcodes für viele Käufer. Den Zeitraum steuerst du über die Ticketstufe selbst. Jedes Ticket trägt einen Teilnehmernamen, den du als Veranstalter ändern kannst. Am Einlass zeigt die Check-in-Statistik pro Stufe, wie viele Mitglieder, Sponsoren und Helfer gekommen sind.

Rabatt- oder Gutscheincodes, die den Preis im Checkout senken, gibt es bei Eventoren nicht. Mitgliederpreise legst du als eigene Stufe an. Fragen zur Einrichtung beantwortet das Team über [Kontakt](/kontakt).

## Häufige Fragen

### Was ist ein Presale-Code?

Ein Presale-Code ist ein Zugangscode, mit dem eine ausgewählte Gruppe Tickets vor dem öffentlichen Vorverkauf kaufen kann. Typisch sind Codes für Fanclubs, Newsletter-Abonnenten, Vereinsmitglieder oder Sponsoren. Der Code schaltet im Ticketshop eine sonst unsichtbare Ticketart frei.

### Was ist der Unterschied zwischen Freischaltcode und Rabattcode?

Ein Freischaltcode macht eine geschützte Ticketart sichtbar und kaufbar. Ein Rabattcode senkt den Preis einer öffentlichen Ticketart. Einen Mitgliederpreis kannst du mit beiden Methoden umsetzen: per Freischaltcode als eigene, günstigere Ticketart oder per Rabattcode auf die reguläre.

### Wie verhindere ich, dass ein Presale-Code geteilt wird?

Ganz verhindern lässt sich das nicht. Du begrenzt den Schaden mit Einzelcodes statt Sammelcodes, einem eigenen Kontingent pro Code-Ticketart, einer passenden Höchstzahl pro Bestellung und persönlicher Verteilung statt öffentlicher Posts. Wird ein Code trotzdem öffentlich, schließt du die Stufe und verteilst neue Codes.

### Wie lange vor dem öffentlichen Verkauf sollte der Presale starten?

Für Vereine und lokale Events reichen meist 3 bis 7 Tage. Bei Fanclub- oder Newsletter-Presales sind 1 bis 3 Tage üblich. Wichtig ist, beide Termine gleichzeitig anzukündigen, damit sich das öffentliche Publikum nicht übergangen fühlt.

### Kann ich mit Freischaltcodes ein Gästelimit beim Abiball durchsetzen?

Ja, wenn jeder Code nur für eine Bestellung gilt. Jeder Abiturient bekommt einen persönlichen Code für die Gäste-Stufe, und die Höchstzahl pro Bestellung entspricht der erlaubten Gästezahl. Ohne Code ist die Gäste-Stufe nicht kaufbar, und nach der Bestellung ist der Code verbraucht. Wer mehr Gäste mitbringen darf, bekommt vom Komitee einen zweiten Code. Legt diese Regel vorher im Jahrgang fest.
